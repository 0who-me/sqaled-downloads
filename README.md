# sQaled for Windows

[Download the latest installer](https://github.com/0who-me/sqaled-downloads/releases/latest/download/sQaled-Setup.exe)

This public repository contains Windows installers and update metadata only. The sQale application source is maintained separately.

## Update an existing installation

Open sQaled and choose **Download update** from its workspace or sign-in screen. Quit the old app from the Windows system tray, then run the downloaded installer. It installs over the existing app and keeps your account and business data.

Starting with version 0.3.0, the floating Settings menu can check for updates, download them, and restart to install.
